# Andes Fulfillment Solutions — landing page

Single-page static site for a fictitious company (SIE 415-515, Project Assignment 3, Group 4).
Plain HTML/CSS/JS, no build step.

- `index.html` — page content
- `styles.css` — styles
- `script.js` — mobile menu, scroll reveals, number count-ups, active-section nav, table bars, back-to-top
- `assets/logo.png` — original logo; `assets/logo-web.png` — transparent, cropped copy used on the page
- `assets/logo-no-text.png` — icon only; `favicon.ico`, `favicon-32.png`, `favicon-192.png`, `apple-touch-icon.png` are generated from it

## Deploy on GitHub Pages

Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)`.
